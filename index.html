Comment on travaille

Un processus simple, sans surprise

  1. 1. Appel découverte (30 min)

    On clarifie le besoin, les contraintes, le budget et le délai. Gratuit, sans engagement.

  2. 2. Proposition & scope

    Je vous envoie un périmètre écrit : livrables, jalons, stack et estimation réaliste.

  3. 3. Exécution en sprints courts

    Points réguliers (async ou call), démos intermédiaires, ajustements si le besoin évolue.

  4. 4. Livraison & passation

    Code documenté, README, handover et recommandations pour la suite (maintenance, V2).

FAQ freelance

Questions fréquentes

Quels types de projets acceptez-vous ?

Missions data/ML, automatisation Python, prototypes web (React/TS) et conseil blockchain. Je décline les projets flous sans objectif mesurable — on définit toujours un livrable avant de démarrer.

Comment se passe la facturation ?

Forfait au scope validé (recommandé) ou facturation par jalons. Un acompte peut être demandé sur les missions > 2 semaines. Paiement selon modalités convenues (virement, Wise, crypto sur demande).

Quels délais viser ?

Un MVP data ou script d'automatisation : souvent 1–2 semaines. Projet ML complet ou app web : 3–6 semaines selon scope. Je préfère sous-promettre et livrer tôt.

Travaillez-vous en anglais ?

Oui. Documentation, calls et livrables peuvent être en français ou en anglais selon votre équipe.

Propriété du code ?

Sur mission payée, le code livré vous appartient une fois le paiement finalisé, sauf composants open source tiers déjà sous licence publique.
